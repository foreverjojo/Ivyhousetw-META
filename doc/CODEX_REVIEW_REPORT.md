## 🔍 Codex 發現的改進點

### 改進點 1: 避免文件矛盾
**位置**: `explore_cli_tool.md` vs `TOOL_USAGE.md`

**問題**: 兩處都說明了「逐步加參數」，但範例不一致：
- `explore_cli_tool.md:51` 用通用範例
- `TOOL_USAGE.md` 用 `-c` 當範例（容易誤導成所有工具都有 `-c`）

**建議**: 
- ✅ **已調整**: 將 `TOOL_USAGE.md` 的範例改為更通用的形式
- 或明確標註「此為 Codex 專屬參數」

### 改進點 2: 釐清「自動讀取」的表述
**位置**: `doc/TOOL_USAGE.md:45`

**問題**: 
> "Codex 會自動讀取 workdir 的檔案"

這容易誤導成「不用在 prompt 指定路徑」，但實際上：
- Codex **可以**讀取檔案，但需在 prompt 中**明確指定路徑**
- Sandbox 受限時可能無法讀取

**建議**:
- ✅ **修正表述**: 改為「Codex 可讀取工作目錄的檔案（需在 prompt 指定路徑）」
- 補充 sandbox 受限時的替代方案

### 改進點 3: 統一術語
**位置**: 多處

**問題**: 
- 有時稱「子命令」，有時稱「subcommand」
- 建議統一使用中文「子命令」

**建議**: ✅ **已修正**: 統一使用「子命令」
